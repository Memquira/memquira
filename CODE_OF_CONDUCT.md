# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and do not harass, insult or exclude anyone. This
applies in issues, pull requests, discussions and any other project space.

Report unacceptable behaviour privately to the maintainers through the contact listed on the
[Memquira GitHub organization](https://github.com/memquira) profile. Reports are handled confidentially. The
maintainers may remove, edit or reject contributions, and temporarily or permanently ban participants, that do not
follow this code.
